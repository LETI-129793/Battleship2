## 1. Cheiro no código escolhido

O cheiro no código escolhido foi **Long Parameter List**, do catálogo de Martin Fowler.

Este cheiro ocorre quando um método recebe demasiados parâmetros, dificultando a leitura, compreensão, utilização e manutenção do código.

## 2. Mapeamento entre o cheiro e a inspeção

| Elemento | Descrição |
|---|---|
| Cheiro no código | Long Parameter List |
| Inspeção no IntelliJ | Method with too many parameters |
| ID da inspeção | `ParametersPerMethod` |
| Métrica utilizada | PAR — Número de parâmetros por método |
| Valor-limite configurado | 5 |
| Condição de deteção | Métodos com mais de 5 parâmetros |
| Limitações | A inspeção utiliza um limite absoluto e não considera diretamente o contexto, a complexidade ou a finalidade dos parâmetros. |

O limite de 5 parâmetros foi configurado no perfil de inspeção. Este valor foi utilizado como aproximação prática à deteção do cheiro Long Parameter List.

## 3. Configuração e resultados

Foi criado um perfil personalizado do Qodana para executar a inspeção `ParametersPerMethod`, com o limite `m_limit: 5`.

Foi utilizado o Qodana for JVM Community 2026.2, configurado para Java 21.

Na análise inicial, o Qodana não identificou problemas com o perfil personalizado, e o Quality Gate passou.

## 6. Reflexão

O Qodana detetou corretamente o método com 6 parâmetros introduzido no teste, fazendo falhar o Quality Gate, enquanto a análise inicial não identificou problemas. A inspeção pode produzir falsos positivos, porque um método com muitos parâmetros pode ser justificável, e falsos negativos, porque um método com poucos parâmetros também pode apresentar problemas de legibilidade. Os resultados são sensíveis ao limite configurado, sendo expectável que limites mais baixos produzam mais alertas e limites mais altos deixem passar mais situações potencialmente problemáticas. Comparativamente às estratégias do livro *Object-Oriented Metrics in Practice*, esta configuração é uma aproximação simples, pois utiliza apenas um limite absoluto para o número de parâmetros, sem combinar métricas nem aplicar limiares relativos ao sistema.
