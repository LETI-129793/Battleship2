## 1. Regra selecionada

Foi selecionada a regra `MethodName` do Checkstyle, responsável por verificar os nomes dos métodos Java.

A expressão regular utilizada é:

`^[a-z][a-zA-Z0-9]*$`

Esta regra exige que os nomes dos métodos comecem por uma letra minúscula e contenham apenas letras e números, seguindo uma aproximação à convenção *camelCase*.

O ficheiro de configuração é `checkstyle-129780.xml`, localizado na raiz do projeto.

## 2. Integração com GitHub Actions

Foi criado o workflow `.github/workflows/checkstyle-129780.yml`, que executa o Checkstyle através do Maven quando é aberto ou atualizado um Pull Request.

O workflow utiliza a configuração individual do aluno e falha quando são detetadas violações da regra definida.

## 5. Limitações da regra

A regra `MethodName` verifica apenas a estrutura dos nomes dos métodos, não conseguindo avaliar se estes são claros ou descrevem corretamente o comportamento implementado. Além disso, a expressão regular utilizada não garante que um nome tenha efetivamente várias palavras em *camelCase*, apenas que respeita o padrão de caracteres definido.
